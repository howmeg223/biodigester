Run python -m pip install -r requirements-test.txt, then python -m pytest -q.

All tests use the current JSON MQTT interfaces. test_control_logic also preserves
coverage of the legacy pure Regulator used for teaching, with explicit watts
passed to the thermal model.

- test_current_services: faults, readings, callbacks, dashboard and simulation
- test_control_logic: boundaries, timers, faults and closed-loop thermal behavior
- test_monitoring: CSV, retained/stale data, ranges, callbacks and demo cleanup
- test_ph_monitoring: pH validation, notification-only limits and sample timing
- test_hardware: GPIO mocks, ADC clocks, calibration, pressure modes, bubbles,
  bridge reversal, watchdog/latch/reset and SH1106 OLED construction/rendering
- test_end_to_end: real MQTT via a private ephemeral local broker, never the
  production broker. Skipped if optional amqtt dependency is unavailable.

No test controls real Pi GPIO. Hardware acceptance checks are in HARDWARE.md.

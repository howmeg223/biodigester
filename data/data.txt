The data folder holds CSV files generated by the monitoring service.

readings.csv:
- stores new sensor readings for history charts and reports
- columns: timestamp, sensor, value
- saved broker readings are not added again

fault_events.csv:
- stores fault changes for later review
- columns: timestamp, event, code, category, severity, message, action
- events include RAISED, REASSERTED, ACKNOWLEDGED, CONDITION_CLEARED and CLEARED

Files are created automatically when the first reading or fault event is logged.
Paths are configured in config.py. CSV files can be opened in a spreadsheet.
